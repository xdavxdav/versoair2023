================================================================================
                    HOW AUTHENTICATION WORKS NOW
================================================================================

AUTHENTICATION FLOW:
  1. User submits email + password to /auth/login
  2. Server returns JWT token
  3. Frontend saves token to localStorage
  4. useAuth() hook detects token and calls /api/user
  5. /api/user validates token and returns user object
  6. useNotifications() receives user object
  7. Socket.io connects and authenticates in user_{userId} room
  8. Real-time notifications flow to correct user

NOTIFICATION FLOW:
  1. User A sends connection request to User B
  2. Server emits to Socket room: user_B
  3. Only User B's connection receives the event
  4. User B's Socket.io listener triggers
  5. Notification added to state
  6. Blog.tsx component re-renders
  7. Bell icon shows unread count
  8. Notification panel displays message
