Place the GoldenBeach font files here so the app can load them.

Expected filenames (examples):

- GoldenBeachPersonalUse-BdIt.woff2
- GoldenBeachPersonalUse-BdIt.woff
- GoldenBeachPersonalUse-BdIt.ttf
- GoldenBeachPersonalUse-BdIt.otf

You can obtain the font file from your license source and drop them into this folder.

After adding the files, the font will be available to the `VersoairDistortion` canvas.
